# 任务 02 · 批量新增主机 — frontend.md（前端执行）

> 视觉与组件规范遵循任务 01 的设计令牌（tasks/01-menu-beautify/frontend.md），

## 1. 入口

主机页筛选行右侧，"新增主机"主按钮旁增加 ghost 按钮"批量新增"。

## 2. 批量新增弹窗（宽 640）

| 字段 | 控件 | 说明 |
|------|------|------|
| 凭据 | 下拉（必填） | 复用凭据列表接口；无凭据时引导先去凭据页 |
| IP 列表 | textarea 6 行（必填） | placeholder 示例：`172.16.1.11-20`（范围）换行 `172.16.2.5`（单 IP）；支持逗号/分号/空格分隔 |
| 角色 | 下拉 | nginx/harbor/k8s/other，默认 other |
| 端口 | 数字输入 | 默认 22 |
| 备注 | 文本 | 选填，统一应用本批 |
| 创建后自动测试 | 开关 | 默认开（对应 auto_test） |

## 3. 实时解析预览

- 输入防抖 300ms 后前端本地解析（与后端同语法的轻量镜像实现）：
  展示"已解析 N 个 IP（去重后）"；与当前主机列表 IP 比对，
  提示"其中 M 个已存在将跳过"。
- 存在非法项时红字提示首个非法项，但**不阻断**提交（最终解析以服务端
  为准，服务端拒绝会返回 3001 并 ElMessage 展示）。
- 预览仅提示作用，禁止用前端解析结果直接构造请求体（ips 原样上送）。

## 4. 提交与结果反馈

1. 提交按钮长 loading（axios 该请求超时 5 分钟），期间禁用弹窗所有控件，
   文案切换"正在批量创建并测试，可能需要数分钟…"。
2. 成功（code=0）：关闭表单弹窗，打开结果弹窗：
   - 顶部汇总条：成功 X · 失败 Y · 跳过 Z（对应 created/failed/skipped 计数）。
   - 表格按 成功（绿）/失败（红）/跳过（灰）分组：IP（等宽）、自动取得的
     名称、失败原因（按 error_code 映射文案，同 04-api §2）。
   - 底部按钮："关闭并刷新列表"（默认）/"仅关闭"。
3. 3001/3002：ElMessage.error 展示 message，保留用户已输入内容。

## 5. 复用与一致性

- 角色徽章、状态徽章、按钮、弹窗骨架全部复用任务 01 的全局组件样式，
  不新增平行样式；新增样式仅追加到 style.css 并走 CSS 变量。
- 文案中文固定；等宽字体用于 IP/端口列（ui 规范 §2.2）。

## 6. 验收自检

- [ ] 三种语法输入预览计数正确，非法项有红字提示
- [ ] 重复 IP 有"将跳过"提示，提交后结果弹窗跳过组正确
- [ ] 长耗时请求期间无重复提交、无控件可操作
- [ ] 结果弹窗三组状态渲染正确，关闭后主机列表已刷新
- [ ] 浏览器控制台零报错，无新增外网请求
